# Política de Segurança

## Versões com suporte

| Versão | Suporte |
|---|:---:|
| 1.3.x (mais recente) | ✅ |
| < 1.3.0 | ❌ |

## Como reportar uma vulnerabilidade

A segurança do Lya Studio Coder é levada a sério. Se você encontrar uma falha
de segurança, **não abra uma issue pública**.

1. Use o canal privado **[Security Advisories](https://github.com/StudioCodeAI/Lya-Studio-Coder/security/advisories/new)** do GitHub, **ou**
2. Envie um e-mail para o mantenedor com o assunto `[SEGURANÇA] Lya Studio Coder`.

Inclua, se possível: descrição da falha, passos para reproduzir, impacto
potencial e versão afetada.

## O que esperar

- **Confirmação** do recebimento em até 72 horas.
- **Avaliação** e classificação de severidade.
- **Correção** priorizada conforme a severidade, com crédito ao relator (se desejar).

## Princípios de privacidade

O Lya Studio Coder é **local-first**: dados do usuário e chaves de API permanecem
na máquina do usuário. Nenhuma credencial é coletada pelos autores.
