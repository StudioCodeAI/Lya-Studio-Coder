## 1. Declaração de titularidade

A **LC REPRESENTAÇÕES LTDA**, inscrita no CNPJ sob o nº 52.867.002/0001-86,
declara, para todos os fins de direito, ser a **única e legítima titular** do
software **Lya Studio Coder**, abrangendo:

a) o código-fonte, em sua integralidade;
b) a identidade visual, marca e denominação "Lya Studio Coder";
c) a documentação técnica e de usuário;
d) todos os instaladores e pacotes oficiais (`.exe`, `.msi`, `.msix`), de
   qualquer versão já publicada ou que venha a ser publicada.

## 2. Substituição das declarações anteriores

Este certificado **substitui e consolida** as declarações de propriedade
anteriormente emitidas por versão (1.0.1 e 1.0.2), permanecendo válido para
todas as versões subsequentes, sem necessidade de reemissão a cada lançamento.

## 4. Vinculação criptográfica dos artefatos

Os instaladores oficiais de cada versão são identificados por resumo
criptográfico **SHA-256**, publicado na página do respectivo GitHub Release e
refletido no repositório oficial. O registro de publicação do GitHub confere
data e integridade a esses resumos, vinculando cada artefato a este
certificado. O pacote MSIX distribuído pela Microsoft Store é adicionalmente
assinado pela Microsoft na certificação da loja, vinculado à conta da titular
no Partner Center (Store ID `9NRW0DWTW9Z8`).
