📦 Instalador direto

O arquivo na sua mão, com o SHA-256 publicado para conferência. .exe para uso pessoal, .msi para implantação corporativa, .msix para sideload com identidade.

Arquivos da v1.3.2

Todo instalador publicado tem o hash registrado. Baixou? Confira antes de rodar.

ArquivoPara quemTamanho
Lya Studio Coder_1.3.2_x64-setup.exe Maioria dos usuários — instala por usuário, sem admin ~58 MB
Lya Studio Coder_1.3.2_x64_en-US.msi Ambientes corporativos — implantação via política ~90 MB
LyaStudioCoder_1.3.2.0_x64.msix Microsoft Store / sideload com identidade Partner Center ~95 MB

Conferir o hash no PowerShell

Get-FileHash "Lya Studio Coder_1.3.2_x64-setup.exe" -Algorithm SHA256

Compare o resultado com o SHA-256 publicado na página da release. Diferente? Não execute — baixe de novo pela fonte oficial.

SmartScreen no .exe/.msi: pode aparecer o aviso de "editor desconhecido" — clique em Mais informações → Executar assim mesmo. Quer instalação sem nenhum aviso? Use a Microsoft Store.

Instalou. E agora?

O caminho mais curto entre abrir a IDE pela primeira vez e ver a IA trabalhando no seu código.

  1. Abra a IDE e escolha na tela de boas-vindas: criar um projeto do zero, abrir uma pasta existente ou clonar um repositório do Git.
  2. Conecte um motor. Sem chave de API? Instale o Ollama e baixe um modelo local — funciona offline e não custa nada.
  3. Converse com a orquestradora no chat e peça a primeira alteração. Ela lê e escreve no workspace de verdade.
  4. Quando a tarefa tiver frentes paralelas, abra a Orquestração e dispare uma missão com a equipe inteira.
