## 🎯 Como Criar Tópicos & Discussões

### **Para Sugerir uma Melhoria (Recomendado)**

1. **Acesse:** [GitHub Discussions → Feature Ideas](https://github.com/StudioCodeAI/Lya-Studio-Coder/discussions/new?category=feature-ideas)
2. **Preencha:**
   ```
   Título: [Breve descrição da melhoria]
   Exemplo: "Adicionar atalho customizável para mudar de provedor"
   
   Descrição:
   - **O que você quer?** (descrição clara)
   - **Por que faz falta?** (problema que resolve)
   - **Como você imagina a solução?** (sugestão de implementação)
   - **Exemplos ou mockups?** (se houver)
   ```

3. **Exemplo prático:**
   ```
   ## 🎯 O que você quer?
   Adicionar tema escuro e light automático baseado na configuração do Windows
   
   ## ❓ Por que faz falta?
   Muitos usuários usam modo escuro no Windows e gostariam que a Lya 
   acompanhasse essa configuração automaticamente
   
   ## 💡 Como você imagina?
   - Detectar configuração do Windows (Light/Dark/Auto)
   - Sincronizar com o tema da Lya
   - Opção para forçar um tema específico
   
   ## 📸 Mockup / Referência
   [Se tiver, compartilhe screenshot ou link]
   ```

4. **Comunidade vota!** 👍 — quanto mais upvotes, maior a prioridade

---

### **Para Discussão de Melhoria (Brainstorm)**

1. **Acesse:** [GitHub Discussions → Melhorias Propostas](https://github.com/StudioCodeAI/Lya-Studio-Coder/discussions/new?category=melhorias-propostas)
2. **Ideale junto com a comunidade:**
   ```
   Título: [Brainstorm] Melhorar performance do terminal
   
   Inicial: Vocês acham que o terminal fica lento em projetos grandes?
   Vamos discutir soluções?
   ```

3. **Discussão aberta** — pessoas comentam, debatem, refinam a ideia
4. **Se ganhar tração** → Vira uma Feature Request formal

---

### **Para Reportar um Bug**

1. **Acesse:** [Issues → Bug Report](https://github.com/StudioCodeAI/Lya-Studio-Coder/issues/new?template=bug.md)

## ❓ FAQ da Comunidade

### Instalação & Setup

**P: Posso usar a Lya em macOS / Linux?**  
R: Ainda não — é Windows-only por enquanto. Mas está no [roadmap](https://github.com/StudioCodeAI/Lya-Studio-Coder#-roadmap)!

**P: Preciso de Node.js instalado?**  
R: Não! O instalador (.exe/.msi) é self-contained — vem com o runtime embutido.

**P: Quanto espaço em disco a Lya usa?**  
R: ~47 MB para instalação + espaço para seus dados (projetos, memória vetorial, etc).

### Usando a Lya

**P: Minhas chaves de API são seguras?**  
R: Sim! Local-first por princípio — suas chaves ficam só no seu computador, nunca são enviadas.

**P: Posso usar múltiplos provedores de IA?**  
R: Sim! Gemini, Claude, GPT, Ollama, Groq, NVIDIA, OpenRouter — todos na mesma IDE.

**P: A Lya funciona offline?**  
R: Parcialmente. Chat local (Ollama) funciona offline. Provedores na nuvem precisam de internet.

### Comunidade & Contribuição

**P: Como faço para sugerir uma feature?**  
R: [Acesse Feature Ideas](https://github.com/StudioCodeAI/Lya-Studio-Coder/discussions/new?category=feature-ideas) e descreva sua ideia. A comunidade vota e quanto mais upvotes, maior a prioridade!

**P: Posso criar plugins para a Lya?**  
R: Sim! Documentação em desenvolvimento. Por enquanto, converse em [Discussions](https://github.com/StudioCodeAI/Lya-Studio-Coder/discussions).

**P: Onde fico sabendo de novas versões?**  
R: 
- [Watch](https://github.com/StudioCodeAI/Lya-Studio-Coder/subscription) o repositório
- Se inscreva em [Announcements](https://github.com/StudioCodeAI/Lya-Studio-Coder/discussions/categories/announcements)
- Siga [@LyaStudioCoder](https://twitter.com/lyastudiocoder) no Twitter/X

**P: Como reporto um bug?**  
R: [Abra uma Issue](https://github.com/StudioCodeAI/Lya-Studio-Coder/issues/new?template=bug.md) com detalhes: versão, SO, passos para reproduzir e screenshot.
